实际游戏中仍待确认：重新启动后进道具店，在列表末尾看到药水、显示 10 铜币、买一瓶药水 +1 且钱 -10，关店重开仍能购买，正常保存重开后数量及钱数正确。版本与验证状态见 `release.json`。
