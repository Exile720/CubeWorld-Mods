# 旅行驿站 0.1.1

新增已登记地点的名称和多行备注编辑。F8 → 选择地点 → “编辑名称/备注” → “保存修改”；可写Boss职业、难度、完成情况和下次准备。列表显示备注摘要，选中后可滚动查看全文。编辑不改变传送落点或城镇编号。

旧 `CWTRAVEL1/2` 地点继续读取，新增或保存时使用带备注的 `CWTRAVEL3`。保存前保留并核对 `stations_backup.bin`；写入失败尝试恢复。安装会备份完整存档与本Mod数据，回退旧DLL时需对应恢复旧格式数据。

完全退出游戏和启动器后运行根目录 `Install-FastTravel.ps1`，默认只更新实验副本的本Mod，沿用原管理器条目和开关。没有自动启动游戏，中文输入、实际保存及重开效果仍待游戏内验收。详见 `../../fast_travel/README.md` 和 `../../research/evidence/fast-travel-0.1.1-validation.md`。
